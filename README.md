# Nikos Efstratiou

**Third-year Electrical & Computer Engineering student at the National Technical University of Athens (NTUA)**  
Interested in **autonomous systems, robotics, computer vision, and optimization**.

I enjoy building systems that connect algorithms with real-world hardware—from UAV mission planning and onboard control to camera-based wildfire monitoring. My work combines software development, embedded systems, and experimentation.

## Selected projects

### [UAV Survey Waypoint Generator](https://github.com/nickefs/citizen-drone-survey-planner)

A web-based tool for generating UAV mapping missions from user-defined survey areas. Combines an interactive **Leaflet** interface with a **C++** survey-planning engine and a **Node.js** backend to generate and visualize waypoints.

### [UAV Companion Computer](https://github.com/nickefs/citizen-drone-companion-computer)

**Raspberry Pi** software for autonomous survey missions using **ArduPilot** and **MAVLink**. Handles mission conversion and upload, camera triggering, and geotagged image capture using flight-controller data.

### [Wildfire Camera Placement Optimizer](https://github.com/nickefs/wildfire-camera-placement)

A **Python/QGIS** workflow for optimizing fixed wildfire-monitoring camera locations and viewing directions. Uses terrain-based viewshed analysis, land-cover weighting, and heuristic optimization, with experiments focused on **Lesvos, Greece**.

### [Lesvos Wildfire Detection](https://github.com/nickefs/lesvos-wildfire-detection)

An evolving prototype for early smoke/fire detection, combining **Raspberry Pi cameras**, **Cloudinary** image transfer, and **YOLO** inference. Includes processing-state tracking and detection logs; performance under real-world field conditions has not yet been validated.
